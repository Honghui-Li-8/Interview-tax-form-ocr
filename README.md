# Interview Assignment

The purpose of this exercise is to gauge your competency as a full-stack software developer. It is not meant to be a riddle, or coding challenge, so don't worry about getting it right. It is more important to show that you know how to read requirements and implement solutions.

You shouldn't have to spend more than 1 hour on this exercise, but feel free to spend as much or as little time as you want.

## Requirements

You can use any programming language/software stack you are comfortable with.

## Task

Create a web-based tax scanning software.

- Users should be able to upload their 1040 tax form
- The software will OCR the form and extract relevant data
- The data will be saved into a form that the user can review and accept

## Evaluation Criteria

Your app will be evaluted using the following criterias

- Using the best practices and convention of your chosen language/software stack
- Leveraging popular tools and libraries of your chosen language/software stack
- Good coding style: formatting, proper naming of variables and functions, etc...
- Logical database design
- Properly implementing the requirements
- The program runs...

## Bonus Points

These things are not required, and will not count against you if you don't do them, but will be a plus. If you do attempt any of these, you should do it correctly...

- Including Automated Tests
- Implementing authentication
- Implementing proper encryption for sensitive data
- Includes installation instructions
- Using source control and leaving good git commit messages
- Deploying the app to a platform like Heroku, AWS, Azure so we can see it in action
